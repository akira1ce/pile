# pile v1.2.1

## 更新内容

- **功能介绍更紧凑**：动画演示与快捷键说明左右排列，减少窗口高度；快捷键范围按当前预设数量显示。
- **设置界面优化**：统一卡片、间距与控件对齐，预设新增尺寸比例示意，调整时更直观。
- **软件更新入口更清晰**：「关于 pile」中的版本信息和更新选项分别成组，自动检查开关与其他设置保持一致。
- **深色外观适配**：功能演示背景随系统外观变化，改善深色模式下的对比度。
- **快捷键提示修正**：明确居中和收起 / 展开需要先关闭设置，窗口切换仍可使用。

## 更新说明

已经安装 1.2.0 的用户可从菜单栏或「关于 pile」点击「检查更新」，确认下载与安装后自动重启到 1.2.1。

此版本继续使用原有 Apple Development 证书和 EdDSA 更新密钥，未经过 Apple 公证。需要 macOS 26 或更新版本。
