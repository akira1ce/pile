# pile v1.1.2

## 更新内容

- **外部左键取消切换**：窗口切换器打开时，左键点击外部即可取消，效果与 Esc 一致；点击仍正常作用于下方窗口。
- **固定证书签名**：改用固定的 Apple Development 证书，保持不同构建之间的应用签名身份一致。
- **源码目录整理**：按应用入口、布局、系统窗口操作、输入和功能分组整理源码，同步更新中英文 README。

## 更新说明

- 请先退出旧版本，再将新版本替换到「应用程序」文件夹，并固定从 `/Applications/pile.app` 运行。
- 从旧的 ad-hoc 签名版本升级时，可能需要重新授予一次辅助功能权限。如果系统设置中已启用 pile，应用仍提示未授权，请删除旧条目并重新添加新应用。
- 此版本未经过 Apple 公证。首次打开可能需要在「系统设置 → 隐私与安全性」中允许打开。

需要 macOS 26 或更新版本。
