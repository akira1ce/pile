# pile v1.2.2

## 更新内容

- **窗口预设更紧凑**：预览与宽高控件并排展示，支持滑块调整和直接输入百分比；删除操作收进预设菜单。
- **滑块显示更简洁**：移除窗口预设滑块的刻度，尺寸比例仍按整数保存。
- **新增展开排列**：支持阶梯、纵向和横向三种方式，沿用收起后的窗口尺寸，共用固定间距，不随窗口数量自动压缩。
- **排列效果预览**：「展开方式」页面随所选模式和间距展示排列示意。
- **保留已有设置**：原来的堆叠模式对应阶梯排列，已有窗口预设和间距继续使用。

## 更新说明

需要 macOS 26 或更新版本。安装包含 Sparkle 的旧版本后，可在本版本发布后从菜单栏或「关于 pile」检查更新。
