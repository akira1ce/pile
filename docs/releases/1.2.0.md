# pile v1.2.0

## 更新内容

- **应用内更新**：菜单栏和「关于 pile」新增「检查更新」，可以查看新版本说明、下载并安装更新，完成后重新启动 pile。
- **自动检查更新**：默认定期检查新版本，可在「关于 pile」关闭；下载和安装由你确认。
- **更新签名校验**：更新描述与安装包均使用独立的 EdDSA 签名验证，安装前校验下载内容。

## 更新说明

- 首次升级到包含更新功能的版本，需要手动安装一次；后续版本可在 pile 内更新。
- 请退出旧版本，将新应用替换到「应用程序」文件夹，并从 `/Applications/pile.app` 运行。
- 此版本使用 Apple Development 证书签名，未经过 Apple 公证；首次打开可能需要在「系统设置 → 隐私与安全性」允许打开。
- 辅助功能授权仍由 macOS 管理。若升级后提示未授权，可在系统设置中删除旧条目，再添加新应用。

需要 macOS 26 或更新版本。
